# Лабораторная работа №3: Асинхронный JavaScript и REST API

## Описание
Интерактивное веб-приложение «Доска публикаций», реализующее взаимодействие с REST API с использованием асинхронного JavaScript (`fetch`, `async/await`). Приложение поддерживает все основные HTTP-методы: **GET**, **POST**, **PUT**, **PATCH**, **DELETE**.

## Способ запуска (основной)

1. Распакуйте архив `Lab3_Шурыгин_БПИ-23-РП-2.zip`.
2. Откройте файл `index.html` в любом современном веб-браузере (Chrome, Firefox, Edge).
3. Серверная часть не требуется — приложение работает напрямую с публичным API JSONPlaceholder.
4. По умолчанию используется адрес: `https://jsonplaceholder.typicode.com/posts`.

---

## Тестирование через локальный сервер (json-server)

Для более полного тестирования (включая реальное сохранение созданных публикаций и работу методов PUT/PATCH/DELETE) можно развернуть локальный REST API с помощью `json-server`.

### Шаг 1. Установка Node.js
Скачайте и установите Node.js с официального сайта: https://nodejs.org/ (рекомендуется LTS-версия).

### Шаг 2. Установка json-server
Откройте терминал (cmd / PowerShell / Terminal) и выполните:
```bash
npm install -g json-server
json-server --watch db.json --port 3000
